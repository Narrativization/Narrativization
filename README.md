# Narrativization
## Introduction
Narrativization is a Narrative Design Software for Game Creators, Screenwriters, and other Storytellers.

## Features
As a Narrative Design Tool, Narrativization will help you create interactive experiences. 

**Planned Features:**
- Story Planning (Plots, Characters, Settings...)
- Screenwriting (Scenario / Branching Scenario Scripting...)
- Visual Novel (Playing / Testing Journey...)
- Import/Export (Game Engines, Documentation, Pdf...)

## About
**Narrativization is Free, Open Source Software for Narrative Design, Story Management, Branching Screenplay (Branching Scenario) writing, and more.**

### Version
Narrativization is currently under development.
